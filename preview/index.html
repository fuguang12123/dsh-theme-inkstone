为什么二分查找中的 right，有时是 nums.length，有时要减 1？

深DeepSeek

关键是先约定：搜索区间是否包含右端点。边界更新与循环条件，都要服从这一个约定。

先约定区间，再更新边界

闭区间 [left, right] 包含右端点，所以初始值是 nums.length - 1。左闭右开区间 [left, right) 不包含右端点，初始值就可以是 nums.length。

区间约定初始 right继续搜索
闭区间 [left, right]length − 1left ≤ right
左闭右开 [left, right)lengthleft < right

把约定写进代码里

Java · 闭区间
int left = 0, right = nums.length - 1;
while (left <= right) {
    int mid = left + (right - left) / 2;
    if (nums[mid] == target) return mid;
    if (nums[mid] < target) left = mid + 1;
    else right = mid - 1;
}

可以先用只有一个元素的数组验证：当 left == right 时，这个位置是否还在待搜索区间里？
