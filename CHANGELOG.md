# Changelog

## 0.1.4

First public release of Inkstone (墨白), an independent DSH community theme.

- Monochrome light and dark palettes, with locally installed LXGW WenKai font fallbacks.
- Sidebar hover and selection use inverted fills inspired by Minimal E-ink.
- Optional colored Markdown headings and underlined links.
- Native font, font-size and appearance preferences remain in control.
- Disabling the plugin releases its token layer and DOM effects.
- Prebuilt tarball, self-contained Git installation build script, attribution and compatibility metadata.
